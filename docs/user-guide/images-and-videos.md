**Images and Videos** is for one-off stills and clips. You type a prompt, pick the same models used in sequences, and the results land in a library you can sort and favorite.

It is not a sequence: there is no script, scene list, or Theatre cut. Use **Sequences** when you want a full film.

## Open the studio

Choose **Images and Videos** in the sidebar, or go to `/studio`.

The gallery is the library. The prompt bar stays at the bottom so you can generate without losing the grid.

## Generate an image

1. Choose **Image**
2. Write a prompt
3. Pick an image model, aspect ratio, and count (1, 2, or 4)
4. Click **Generate image**

Each still is stored as its own item. Sign in first — generate is gated behind login, same as sequences.

## Generate a video

Sequence video models are image-to-video. A prompt-only clip therefore:

1. Renders a start frame with your image model
2. Animates that frame with your video model

Choose **Video**, write the prompt, pick still and motion models, aspect ratio, duration, and optional native audio, then generate. The library card plays the clip; the start frame is kept with it.

## Sort and keep

- **All / Images / Videos** filter the library
- **Newest** and **Oldest** change recency order
- **Favorites** pins items you star on a card
- Open a card to see the full result and delete it
